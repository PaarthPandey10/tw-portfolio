# Git and GitHub: Command Structure

## The State Tracking Model
1. **Untracked/Modified:** Live changes inside the working tree.
2. **Staged:** Indexed modifications prepared for commit execution.
3. **Committed:** Permanent historical snapshots within the `.git` repository.

## Operational Commands
- `git status` / `git log --graph`
- `git branch -M main` / `git switch -c <branch_name>`
- `git remote add origin <url>` / `git fetch`
